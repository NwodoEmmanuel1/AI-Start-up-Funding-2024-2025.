# AI-Start-up-Funding-2024-2025.

## Tools Used
- Microsoft Excel
- Google sheet.

## Project Overview
This project analyzes the fundings provided to AI companies in the United States of America, United Kingdom, China, France, and Canada based Companies. 

## what I learned
- Investors are more willing to invest in closed source AI companies.
- The USA, during this period, received more than 90% of the fundings.
